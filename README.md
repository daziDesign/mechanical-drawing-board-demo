# 机械制图教学画板 Demo

面向高校机械制图课堂的中文网页画板。此 Demo 按《机械制图教学画板_PRD与技术实现_V1》第十一节的 MVP 范围制作，建议在 1920×1080 或 1366×768 的电脑浏览器中投屏使用。

## 启动

需要 Node.js 和 npm。在仓库根目录执行：

```powershell
cd demo
npm install
npm run dev
```

打开终端显示的本地地址，通常是 `http://localhost:5173/`。首次进入可选“打开 R20 教学示例”或“新建空白画板”。现阶段只在浏览器内保存一个当前项目；开始新项目之前，建议从“文件”菜单导出 JSON 备份。

## 课堂操作

- 左侧选绘图工具，上方单独选九种图线。直线按起点、终点绘制；圆按圆心、圆周点绘制；圆弧可在右侧参数面板切换“圆心／起点／终点”与“三点”两种画法。
- “参数”默认收起，打开后可输入线段长度、圆或圆弧半径、辅助平行线偏移距离，单位均为 mm。绘制直线时按住 Shift 可约束为水平或垂直。
- 辅助平行线先点选已有直线，再点目标一侧，默认偏移 20 mm。顶部“辅助线”控制显示；“辅助作图”可将后续图元标记为辅助线。端点、中点、圆心、交点和象限点按屏幕 10 px 范围捕捉，可关闭。
- 底部可播放、拖动或逐步查看作图过程。回放只读，点击“退出回放”回到最新图样。顶部可撤销、重做、适合画布与全屏；滚轮缩放，平移工具、鼠标中键或空格拖动平移。Esc 取消当前绘制。
- 项目自动保存到本机浏览器 IndexedDB。“文件”菜单可导入／导出完整项目 JSON；SVG 和 PNG 导出当前视口及辅助线可见状态。SVG 使用 mm 线宽，屏幕预览线宽单独处理。

R20 示例含两条已知直线、两条相距 20 mm 的辅助平行线、交点 O、切点 T1/T2、圆弧与半径引出标注。绘图线条可选择、改线型或删除；标注可选择或删除；随后仍可继续绘图。

## 验证

```powershell
cd demo
npm run typecheck
npm test
npm run test:e2e
npm run test:sites
npm run build
```

浏览器测试使用本机 Chrome。截图及视觉核对记录见 [design-qa.md](demo/design-qa.md)。仓库约定检查可在根目录执行 `pwsh -File tests/agents-content.Tests.ps1`。

## 范围与待核准项

- 矩形、修剪、尺寸标注工具、自由笔迹及离线 PWA 不在本轮 MVP 中。R20 示例的引出标注为示例内容，尚无通用标注工具。
- 九种图线名称、粗细线 2:1 关系与两直线圆弧连接步骤参考仓库中的课程课件。粗线导出默认为 0.5 mm，细线为 0.25 mm。虚线与点画线的划段周期、端点处理，以及波浪线、双折线在曲线上的图案细节，尚未依国标全文逐项核准；本 Demo 不宣称达到正式制图标准合规认证。正式教学出图前应结合 GB/T 4457.4—2002 与 GB/T 17450—1998 原文人工校核。
- 目前只做了 Chrome 自动化、两种桌面投屏尺寸和触控事件模拟；真实数位笔、不同投影仪与打印设备尚未实测。
